# Contraste — Precision Atelier

Regra de produto para a interface interna do PintService:

- superfícies claras usam texto principal escuro e texto secundário de contraste confortável;
- metadados operacionais não devem depender de cinza muito pálido nem de fonte abaixo de 9px;
- Dark Surface é reservado para login, exceção, decisão e foco;
- nunca usar texto claro sobre fundo claro nem texto escuro sobre Dark Surface;
- estados desabilitados podem ter contraste menor, mas informação operacional ativa deve permanecer legível;
- foco de teclado precisa ser perceptível;
- legibilidade e performance têm prioridade sobre efeitos decorativos.
