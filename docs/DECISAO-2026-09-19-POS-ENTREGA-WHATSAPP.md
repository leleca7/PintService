# PINT SERVICES — DECISÃO 19/09/2026 — PÓS-ENTREGA E WHATSAPP OPERACIONAL

Este documento registra a direção aprovada para a próxima evolução do Sistema da Pint.

## Princípio de produto

A equipe atualiza a operação uma vez. O sistema reutiliza a informação para atendimento, IA, peças, tarefas, pós-entrega, garantia e reputação.

O funcionário não deve precisar permanecer no painel para resolver dúvidas simples. Quando uma informação puder ser obtida com segurança pelo WhatsApp, o Sistema da Pint deve levar a exceção até a pessoa responsável.

## Finalização

A saída do veículo passa a ter duas decisões explícitas:

- Veículo finalizado — sem pendências.
- Veículo finalizado — com pendências.

Quando existir pendência, sua descrição é obrigatória e continua rastreável mesmo depois que o veículo sai da fila de produção.

## Pós-entrega

A finalização inicia um fluxo de pós-entrega. Os períodos de garantia ficam configuráveis e são congelados no veículo no momento da saída.

A comunicação inicial deve informar a garantia e solicitar percepção sobre o serviço. A resposta do cliente é interpretada pela IA.

Resposta positiva pode liberar o link de avaliação. Resposta neutra ou negativa não deve receber pedido de avaliação. Resposta negativa cria atendimento humano.

## Pendência pós-entrega

O cliente deve ser comunicado quando houver mudança real na pendência, e não por mensagens repetitivas sem novidade.

Eventos relevantes: pedido confirmado, previsão registrada, peça recebida, agendamento disponível e pendência resolvida.

## Funcionário via WhatsApp

O fluxo operacional já existente de tarefas pelo WhatsApp será a base.

Quando o cliente pedir uma informação que não está preenchida, o sistema pode abrir uma tarefa para o responsável do veículo. O funcionário responde pelo WhatsApp com a informação e, quando aplicável, foto.

Antes de enviar ao cliente, a resposta é confirmada pelo funcionário. A IA reorganiza o texto para ficar claro e profissional sem alterar os fatos.

A prioridade de roteamento é o responsável já vinculado ao veículo. Quando não houver responsável, o sistema pode usar um único funcionário ativo do setor. Se a atribuição continuar ambígua, a tarefa permanece para tratamento humano em vez de escolher alguém arbitrariamente.

## Segurança

IA interpreta; sistema aplica regras; banco confirma fatos; humano resolve exceções.

Nunca inventar preço, prazo, etapa, peça recebida, disponibilidade, status físico ou data de entrega.
